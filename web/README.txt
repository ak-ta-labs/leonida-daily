LEONIDA DAILY - Frontend Prototype v0.1

HOW TO RUN
1. Open the repository in Visual Studio Code.
2. Open web/designHTML.html with Live Server.
3. Keep styles.css and assets/ in the web/ directory.

CURRENT FUNCTIONALITY
- Dark neon interface.
- Category filtering.
- Local search.
- Article preview modals.

LIMITATIONS
- Articles, weather and trends are demonstration content.
- Images are cropped from the AI-generated design concept.
- Newsletter subscription is a visual prototype.
- No n8n, API or database integration yet.

The frontend will be updated after the shared data contract is approved.
